# The pipeline: one file per stage

Each stage says when it runs, which workflows it uses, what it produces, and how to know it is done. This is the one map of stages to workflows. The procedures themselves are in [plan/workflows/](../../plan/workflows/README.md), each complete in itself; the reasons are in [kit/method/](../method/README.md).

| # | Stage | Tier | What it is for |
|---|---|---|---|
| [01](01-intake.md) | Intake | Basic | know the existing work before asking |
| [02](02-interview.md) | Interview | Basic | get the book in the writer's head onto paper |
| [03](03-set-up-plan.md) | Set up plan/ | Basic | the folders and plan files |
| [04](04-card-the-work.md) | Card the existing work | Basic | facts on cards; existing scenes as outlines |
| [05](05-checks-before-outlining.md) | Checks before outlining | Refinement | flaws found before they are outlined; the horizon |
| [06](06-outline.md) | Outline | Basic | marked beats and the reader-test spec |
| [07](07-key-frames-and-dictation.md) | Key frames and dictation | Refinement | the writer's frames for thin chapters |
| [08](08-notes-then-render.md) | Notes, then render | Basic | the draft |
| [09](09-refine.md) | Refine | Basic | the draft checked and revised |
| [10](10-read.md) | Read | Basic | readers and the writer test the prose |
| [11](11-close.md) | Close | Basic | sessions, tasks and waves end clean |
| [12](12-accept-and-release.md) | Accept and release | Refinement | a volume accepted, archived, checked for release |

**Stages 08 and 09 are the core.** Their detail is in [plan/workflows/drafting/](../../plan/workflows/drafting/README.md), the kit's largest section.

**Stages 06 to 10 repeat** for each horizon. The session close in stage 11 runs at the end of every session, whatever stage the book is in.

**Upkeep, at any stage:** [apply-terms](../../plan/workflows/apply-terms.md), [readings-inventory](../../plan/workflows/readings-inventory.md), [restructure](../../plan/workflows/restructure.md), [ledger-roll](../../plan/workflows/ledger-roll.md), each with its trigger.

**Every stage runs as tasks and waves** ([kit/method/tasks-and-waves.md](../method/tasks-and-waves.md)).
