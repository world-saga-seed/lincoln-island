# *L'Île mystérieuse*, the French (Hetzel, 1875): where it came from

*Handed over by the author, 2026-11-20; see "Not yet done".*

- **Edition:** Jules Hetzel et Cie, Paris, 1875, illustrated by Jules Férat (Wikisource's scan index, `Livre:Jules Verne - L’Île mystérieuse.djvu`).
- **Scan:** Gallica, BNF ARK `bpt6k1033380`, which is the scan the transcription was made from.
- **Transcription:** fr.wikisource, `L’Île mystérieuse`, marked "Textes validés". There are 62 chapter pages: Partie 1 has chapters 1 to 22, Parties 2 and 3 have 1 to 20 each.
- **Fetched:** 2026-11-20, by the MediaWiki API (`action=parse`, `prop=text|revid`), one call per chapter. Each page's revision id is in `raw/manifest.json`, so every page can be fetched again exactly at `https://fr.wikisource.org/w/index.php?oldid=REVID`.
- **Files:** `raw/01.html` to `raw/62.html` are the rendered chapter HTML as the API returned it, unchanged. `SHA256SUMS` holds the sha256 of each.
- **Size:** about 200,700 words in paragraphs.
