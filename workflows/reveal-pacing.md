# Reveal pacing: what the reader can know, and when

*Refinement. Add this when the book withholds a large truth.*

An agent maps what a careful reader can know after each chapter, and flags any secret that can be worked out before the book means to give it. Run it when the outlines of a horizon are settled, whenever a secondary layer (letters, interludes, other narrators) is added or moved, and before drafting.

**Grade.** A judgment, like a critic. Findings quote the text. The writer decides which reveals move.

## The loop

1. **Open a task** naming the scope and the start hash.
2. **One fresh agent** (never a fork: it must read the page, not the writer's reasoning) builds the ladder ([prompt](#prompt)).
3. **Verify:** quotes resolve; cited headings exist.
4. **Present to the writer** one finding at a time, earliest in the book first.
5. **Fold back:** moves and cuts into the outlines; placement rules into the clue register (`plan/reread-hooks.md`).

## Prompt

> You are checking the reveal pacing of a novel in progress, in the folder {REPO}. Read the notes in `story/` and `world/` and the outlines {SCOPE}. Write only {OUTPUT}; run no git commands; do not launch agents. (1) **The withheld truths:** every large truth the book holds back from the reader, with its file and heading, and any rule the notes give for when it lands. (2) **The ladder:** in page order, what a careful reader can know after each chapter, and from which text. Count what can be put together from two or more places, not only what one states. (3) **Early reveals:** every point where a truth can be worked out before its planned moment. Separate a **hint** (a reader may wonder) from a **reveal** (a reader can work it out). Quote the text that gives it away. (4) **Remedies,** marked proposal, each with its cost: hold it later, cut a scene short, keep a name back, swap an order. (5) **Open questions** for the writer. Do not edit anything else.

## Lessons

- A hint is the point. A puzzle the reader can never solve is not fair; one solved three volumes early is not a puzzle. The remedy is usually order, not removal: never cut a clue to slow a reveal.
