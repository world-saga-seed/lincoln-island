# 05 Checks before outlining

*Refinement. Add this when an arc of several chapters is about to be outlined.*

**When:** once an arc's key frames are settled, before it is outlined chapter by chapter.

**Uses:** [logic-check](../../plan/workflows/logic-check.md), [consistency-check](../../plan/workflows/consistency-check.md) (on what is already outlined), [reveal-pacing](../../plan/workflows/reveal-pacing.md), [echo-audit](../../plan/workflows/echo-audit.md) (where outcomes rhyme with real history).

**What happens:** fresh agents find what cannot work, what drifted and what is revealed too early; the writer rules; then the **horizon** is set ([kit/method/horizon.md](../method/horizon.md)).

**Done when:** every finding is fixed, ruled on, or held; the horizon is written in `CLAUDE.md` and a horizon file.
