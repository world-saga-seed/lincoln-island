# Lincoln Island

Jules Verne's *L'Île mystérieuse* with one chapter inserted. The byline is "Jules Verne; the missing chapter by a model, by the World Saga Seed method". The run demonstrates the [World Saga Seed](https://github.com/world-saga-seed/world-saga-seed) kit; the phases are in [BRIEF.md](BRIEF.md) and the working rules in [CLAUDE.md](CLAUDE.md).
