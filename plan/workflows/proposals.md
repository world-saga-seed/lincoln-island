# Proposals: a guide to a set of things

*Refinement. Add this when the setting needs a set of things the notes leave thin.*

An agent drafts a guide to a set of things in the setting (towns, families, guilds, ships, schools), with proposed names and histories, assembled from what the notes already say and filled where they are silent. The writer settles or cuts each item.

**Grade.** A judgment. Nothing is canon until settled.

## Rules for every guide

- **Separate what the notes say from what is invented.** Every item is *(Settled …)* with its source, or *(Proposal.)*.
- **Combine before inventing.** Use what the notes already hold first.
- **Names follow the setting's language and history,** and collide with no existing term (check the cards).
- **History fits the timeline** in the notes.
- **What the page shows stays apart from reference detail:** say what the narrator would know or call it, and what only the writer knows.
- **The world is no fool:** anything backward or strange has a reason that is the right choice under the setting's rules.
- **Every entry ends in Open questions** for the writer, each with a recommendation.

## The loop

1. **Open a task** naming the set and the start hash.
2. **One agent drafts the guide** into one file, read-only elsewhere.
3. **Verify:** cited headings exist; every item marked settled says what its source says. Downgrade anything that does not to a proposal.
4. **Present to the writer** one entry at a time, with its questions.
5. **Move the settled items** to their cards; leave the rest marked.

## Prompt

> Draft a guide to {SET} in {FILE}, in the folder {REPO}. Read {REGION} first. Write only {FILE}; run no git commands; do not launch agents. For each entry: proposed name, with where it comes from; when it began and what came before; how it is run; where it is and what it is like; its people and customs; its part in the story; what the narrator knows of it and calls it. Follow the rules for every guide in `plan/workflows/proposals.md`. Mark settled or proposal per item, citing file and heading. End each entry with Open questions.
