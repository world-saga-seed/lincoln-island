The French is the authority. The repository is the current folder; every path below is relative to it. Run no git commands of any kind. Do not launch agents. Work alone. THE RULE the cards keep: a card holds what is true of its subject (nature, traits, skills, possessions, relations, dated changes; for a made thing its making), not the story's events, which the outlines hold; an act goes on a card only when it shows what the subject is or changes it, and in doubt the line is kept. A fact the text states is marked *(Drafted.)*, an inference *(My reading, to confirm.)*; where the text disagrees with itself both readings go on the Open line and neither is carded.

TASK 1. For each of the eight findings, judge:
