# The boat: the vessel Smith would build if land lay within reach

*A boat for leaving the island, to be built "instead of a house" if land were near; given up when the longitude shows the distances.*

Keywords: bateau, embarcation, canot, boat, vessel, escape, sail, leave the island

- **What it is.**
  - Pencroff said that one day or another they would find the means of getting away (I.14 ¶53). *(Drafted.)*
    - quote: nous trouverons le moyen de nous en aller
  - Smith said that if the island lay only two or three hundred miles from New Zealand or Chile, they would make a boat instead of a house, and Pencroff would command it (I.14 ¶61). *(Drafted.)*
    - quote: au lieu de faire une maison, nous ferons un bateau
  - Pencroff would be ready to be captain as soon as Smith found a way to build a craft able to keep the sea (I.14 ¶62). *(Drafted.)*
    - quote: dès que vous aurez trouvé le moyen de construire une embarcation suffisante pour tenir la mer
  - Smith answered that they would build it if need be (I.14 ¶63). *(Drafted.)*
    - quote: Nous le ferons, si cela est nécessaire
  - The longitude showed the island too far from any land to risk the distance in a simple, fragile canoe, so the idea was dropped (I.14 ¶78). *(Drafted.)*
    - quote: on ne pourrait se hasarder à franchir cette distance sur un simple et fragile canot
- **Appears in:** I.14
